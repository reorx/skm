# 发布 SKM 0.4.0

## 概要

按 minor version 将 `skm-cli` 从 0.3.0 升到 0.4.0，在当前 master 分支完成版本与发布准备。本版包含 `agents.override` 路径和安装模式配置、agent 环境变量解析，以及拒绝覆盖、安装目录别名、相对 override 路径和 home 路径边界的修复。

验证：`uv run pytest -q` 全部 220 项通过（含联网测试）；源码包和 wheel 构建成功，检查了版本元数据、新增 agents 模块及临时文件排除；在隔离环境安装 wheel 后运行 `skm --help` 成功。

发布产物位于 `tmp/2026-10-29-release-0.4.0/dist/`。上传使用 `uv publish` 并明确指定本版的 wheel 和源码包；Git 使用 `v0.4.0` 标签。

## 修改的文件

- `pyproject.toml`、`uv.lock`：版本同步至 0.4.0，依赖不变。
- `AGENTS.md`：记录版本升级、验证、构建和发布约定。

## 注意事项

- PyPI 发布前确认线上版本为 0.3.0，且 0.4.0 尚不存在。
- 构建输出使用本次专属目录，避免默认 dist 目录中的历史产物被一起上传。
- 发布后通过 PyPI 版本接口和隔离安装复核线上产物。

## 遗留问题

现有已知问题继续由 [known-issues](../known-issues.md) 跟踪，本次不修改功能代码。
