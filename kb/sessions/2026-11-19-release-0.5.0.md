# 发布 SKM 0.5.0

## 概要

按 minor version 将 `skm-cli` 从 0.4.0 升到 0.5.0。本版包含：`skm install --local` 设备本地 skill 来源，以及 local source 在同名冲突时优先；`source_cmd` dynamic skill 和 `skm install --cmd`；`install -y` 和无终端时提示自动取默认值；README 中 `source_cmd` 的示例。

验证：`uv run pytest -q` 全部 319 项通过（含联网测试）；sdist 和 wheel 构建成功；wheel 里有 `tui.py`、`dynamic.py`、`local_sources.py`；在隔离环境里用 `uvx --isolated --from <wheel>` 运行 `skm install --help`，能看到 `--local`、`--cmd`、`-y, --yes`。

发布产物在 `tmp/2026-11-19-release-0.5.0/dist/`，上传时 `uv publish` 只指定本版的 wheel 和 sdist；Git 标签为 `v0.5.0`。

## 修改的文件

- `pyproject.toml`、`uv.lock`：版本升到 0.5.0，依赖不变。

## 注意事项

- 发布前确认了 PyPI 上的最新版本是 0.4.0，0.5.0 还不存在。
- sdist 里包含 git 跟踪的 `kb/` 文档，和 0.4.0 一样（0.4.0 里有 18 个），没有 `tmp/`。这些内容本来就在公开的 GitHub 仓库里。

## 遗留问题

已知问题继续由 [known-issues](../known-issues.md) 跟踪，本次没有改功能代码。
